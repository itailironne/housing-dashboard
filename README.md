# דשבורד דירות לפי שלב בנייה

דשבורד HTML אינטראקטיבי ועצמאי (Chart.js מוטמע בקובץ, בלי תלות ברשת) שמציג
נתוני הלשכה המרכזית לסטטיסטיקה (הלמ"ס) על דירות לפי שלב בנייה — בבנייה פעילה,
גמר בנייה, התחלת בנייה, היתרי בנייה — ברמה הארצית הרבעונית, וגם פילוח שנתי
מתגלגל לפי יישוב.

🔗 **[צפייה בדשבורד החי](https://itailironne.github.io/housing-dashboard/)**

## עדכון אוטומטי

נתוני הדשבורד מתעדכנים אוטומטית: routine מתוזמן (Claude Code, cron חודשי)
בודק אם התפרסמה הודעת למ"ס חדשה בסדרת "התחלות וגמר בנייה", ואם כן — מוריד,
מחלץ, מאמת ומעדכן את הקובץ בעצמו, ודוחף (push) את הגרסה המעודכנת. מצב הבדיקה
האחרונה נשמר ב-[`data/last_release.json`](data/last_release.json). אם משהו
נכשל (המקור לא נגיש, מבנה הטבלה השתנה וכו') — הריצה **לא** תמציא נתונים; היא
תשאיר הערה ב-`STATUS.md` בשורש הריפו במקום לעדכן את הדשבורד.

לפרטים טכניים מלאים (מבנה הנתונים, שיטת החילוץ, בדיקות שבוצעו) ראו
[HANDOFF.md](HANDOFF.md).
